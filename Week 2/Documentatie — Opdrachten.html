Opdracht 1 — CSV-cijferrapport

Leest een CSV-bestand met studentcijfers in, berekent het gemiddelde en print een rapport van studenten met een cijfer ≥ 80.

openen(file_path: str) -> list[dict]

Opent het opgegeven CSV-bestand en zet elke rij om naar een dictionary via csv.DictReader. Geeft een lijst van alle rijen terug.

ParameterTypeOmschrijving
file_pathstrPad naar het CSV-bestand
Returnlist[dict]Eén dict per studentrecord (kolomnaam → waarde)

Let op: deze functie gebruikt de module csv, die niet is geïmporteerd bovenaan het notebook (alleen pandas en numpy staan er). Zonder import csv geeft dit een NameError bij uitvoeren.

gemiddelde(lijst_: list[dict]) -> int

Berekent het gemiddelde van de kolom Grade over alle records.

Werking:
  • Som alle cijfers (omgezet naar float)
  • Deel door het aantal records

De type-hint zegt int, maar de functie geeft feitelijk een float terug.

filter(lijst: list[dict]) -> None

Filtert alle studenten met Grade ≥ 80 en print naam en cijfer per gevonden student, gescheiden door een streepjeslijn.

Hoofdscript: vraagt de gebruiker om een bestandspad, leest de data in, print het klassengemiddelde en vervolgens het rapport van studenten met een voldoende hoog cijfer.

Opdracht 2 — Mandelbrotverzameling

Genereert en tekent de Mandelbrotverzameling als afbeelding, door voor elke pixel te bepalen hoe snel de bijbehorende iteratie divergeert.

pixelpositie(pixel_x: int, pixel_y: int, width: int) -> complex

Zet een pixelcoördinaat om naar een complex getal binnen het gebied x ∈ [-1.5, 0.5], y ∈ [-1, 1], op basis van de breedte van de afbeelding.

ParameterTypeOmschrijving
pixel_x, pixel_yintPixelpositie in het raster
widthintBreedte (= hoogte) van de afbeelding in pixels
ReturncomplexBijbehorend punt in het complexe vlak

diverging(complex_getal: complex) -> int

Past de Mandelbrot-iteratie z ← z² + c maximaal 100 keer toe, startend bij z = 0.

Werking:
  • Zodra |z| > 2: geeft het aantal iteraties terug (divergentiesnelheid)
  • Na 100 iteraties zonder divergentie: geeft 0 terug (punt hoort bij de verzameling)

create_image(width: int) -> np.ndarray

Bouwt een width × width array op waarin elke cel de divergentie-index van het corresponderende punt bevat.

draw_mandel(lengte: int) -> None

Hoofdfunctie: genereert de afbeelding en toont deze met matplotlib, geschaald naar het venster [-1.5, 0.5] × [-1, 1].

Opdracht 3.1 — Barabási–Albert netwerk

Genereert een schaalvrij netwerk volgens het Barabási–Albert-model (preferential attachment) en visualiseert het.

calculate_probabilities(graph: nx.Graph) -> dict[int, float]

Berekent voor elke node de kans op een nieuwe verbinding, evenredig aan de graad van de node (preferential attachment): kans(v) = graad(v) / Σ graden.

choose_nodes(G: nx.Graph, M: int) -> list[int]

Kiest M unieke bestaande nodes om een nieuwe node mee te verbinden, gewogen naar hun kans.

Werking:
  • Trek één node volgens de kansverdeling
  • Verwijder deze uit de kandidatenlijst en herverdeel de resterende kansen
  • Herhaal tot M nodes gekozen zijn

generate_network(K: int, N: int, M: int) -> nx.Graph

Bouwt het volledige netwerk op.

ParameterOmschrijving
KAantal startnodes (volledig verbonden met node 1)
NUiteindelijk aantal nodes
MAantal koppelingen per nieuwe node

Start met een ster van K nodes rond node 1, en voegt daarna nodes K+1 … N toe die elk via choose_nodes aan M bestaande nodes koppelen.

Opdracht 3.2 — PageRank op een gerichte graaf

Leest een edge-list in (eekhoorn-interactiedata, kolommen id1/id2), bouwt een gerichte graaf en berekent PageRank per node.

openen(file_path: csv) -> list[dict]

Leest een CSV-bestand met csv.DictReader in en geeft een lijst van rijen terug. (De type-hint csv op file_path is onjuist; dit zou str moeten zijn.)

maak_Digraph(squirrel: list[dict]) -> nx.DiGraph

Zet elke rij om in een gerichte edge id1 → id2 en bouwt zo een DiGraph op.

pagerank(G: nx.DiGraph, d: float) -> dict

Eigen implementatie van het PageRank-algoritme (iteratieve power-methode).

Werking:
  • Initialiseer elke node op 1/N
  • Herhaal 100 keer: elke node krijgt (1-d)/N plus een gewogen bijdrage d × (PageRank van elke voorganger / diens uitgaande graad)
  • Nodes zonder uitgaande links ("dangling nodes") verdelen hun PageRank gelijk over alle N nodes
ParameterOmschrijving
GGerichte graaf (nx.DiGraph)
dDempingsfactor (damping factor), gebruikt als 0.85

maak_grafiek(pagerank: dict) -> None

Toont een histogram (log-schaal op de y-as) van de verdeling van PageRank-waarden over alle nodes.

Hoofdscript: leest squirrel_edges.csv in, bouwt de graaf, berekent PageRank met d = 0.85 en toont de verdeling als histogram.
